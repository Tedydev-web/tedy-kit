# Problem registry: least quota at equal quality (quota)

A problem is one behaviour kit use must get right so that a task spends the least Claude Code quota for the same result quality. Problems are listed top-down from a fixed frame, so techniques are searched per problem instead of collected from sources. Generic names only; the user's logs and kit files are evidence, not names. A problem whose only lever lowers quality is out of scope (study plan, Scope) and listed under Dropped candidates.

Status: approved by the user on 2026-10-21 ~08:15 as drafted, with the decisions listed under Decisions. Rows Q8, Q9, Q24 and Q25 were re-checked on Claude Code 2.1.305 on 2026-10-21. The topic config is `docs/prior-art/topics/quota.json`.

## Frame

- SWEBOK Guide V4 knowledge areas (IEEE Computer Society: "Its 18 knowledge areas (KAs) summarize key concepts"): Software requirements; Software architecture; Software design; Software construction; Software testing; Software engineering operations; Software maintenance; Software configuration management; Software engineering management; Software engineering process; Software engineering models and methods; Software quality; Software security; Software engineering professional practice; Software engineering economics; Computing foundations; Mathematical foundations; Engineering foundations.
- ISO/IEC/IEEE 12207:2026 process groups: agreement; organizational project-enabling; technical management; technical.
- Kit-use lifecycle steps (quota study plan, Scope): 1 Session start; 2 Skill load; 3 Work turn; 4 Subagent and orchestration; 5 Wait and idle; 6 Compaction and clear; 7 Hand-off; 8 Measurement.
- What the steps cover: 1 everything that loads before the first request (instructions, memory, skill listing, hooks, settings, auth route); 2 a skill body and the references it pulls; 3 one request of the working session, its tool calls and output; 4 spawning, briefing, reusing and routing subagents; 5 any gap between requests, including waits for subagents and long idles; 6 `/compact`, auto and idle compaction, `/clear`, `/rewind`; 7 hand-offs and messages between sessions; 8 measuring quota and quality.
- Quota proxy: API-equivalent cost at list price, because the subscription weights of cache reads and writes are unpublished (pilot:5, pilot:175). Equal quality means the kit's fact-graded eval score does not drop (ADR 0009).
