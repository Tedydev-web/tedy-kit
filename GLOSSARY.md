# tedy-kit glossary

Words the skills, shared docs and scripts use with one fixed meaning.

## Language

**Draft**:
Unpublished text waiting for the user's approval before anything is posted under their name.
_Avoid_: preview, pending comment, proposal

**Hint**:
One sentence that states the current state and stops there, with no fix attached.
_Avoid_: suggestion, tip, recommendation

**Rebut**:
Verify a claim from a review, a bot or a PR body, then accept it or refute it with evidence.
_Avoid_: dismiss, push back, argue

**Raise**:
Surface a conflict between sources in the same turn, quoting both sides, so the user picks one.
_Avoid_: flag, escalate, mention

**Truth ladder**:
The order sources are checked against each other: the frontend matches the backend and the contract; the backend and the contract match the PRD and Figma.
_Avoid_: source hierarchy, priority order

**Write-guard**:
The line `WRITE → <target> : <count and kind>` a script prints right before an external write, naming where it goes and what it holds.
_Avoid_: dry run, confirmation prompt

**READY**:
The verdict `project-map.mjs doctor` prints when a project map passes every check.
_Avoid_: OK, green, healthy

**Docs-claim**:
A fact taken from documentation that has not yet been checked against the code.
_Avoid_: documented behavior, known fact
